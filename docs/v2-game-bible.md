# 《霧中的臺灣》2.0 — 戒嚴年代異聞錄

> 開發狀態：世界觀與玩法骨架鎖定；案件內容採章節式逐步製作，不預先把所有案件寫死。

## 核心定位

1958 年臺灣戒嚴時期。玩家扮演一名私家偵探，家族具有道士傳承，主要承接失蹤、怪談、地方禁忌與疑似靈異事件。

遊戲不預設「怪事一定有鬼」。案件可能是純人為、自然現象、民俗誤解、人為利用傳說、人為與異常交織，或在結案後仍留下無法完全證實的部分。

核心原則：**先查明發生了什麼，再決定要不要相信有鬼。**

## 統一遊戲循環

所有主要案件沿用序章《失落的三頁》已驗證的玩法：

委託 → 現場探索 → 點擊／觀察物件 → 詢問人物 → 取得證物與情報 → 開放新地點 → 交叉驗證 → 提出證據 → 建立事件鏈 → 最終推理 → 案件處置 → 後續影響。

尚未取得的資訊不得預先顯示成選項；錯誤證據應給方向性回饋，但不能直接暴露正解。

## 主角

職業：私家偵探。

家族背景：家族有道士傳承。主角具備民俗、符籙、祭祀、喪葬、地方神祇、禁忌與科儀方面的知識，但家學不是「辨認真鬼」的答案按鈕。

調查分為兩個互補層次：

- 一般偵探觀察：痕跡、時間、證詞、文件、物證、動機、地理與行動可能性。
- 家學觀察：符式、香灰、供物、禁忌、神祇、儀式、地方傳說與民俗脈絡。

兩類情報都必須回到同一條證據鏈接受驗證。

## 序章／教學案件：《失落的三頁》

保留現行第一案的主要真相、地點、人物、證據鏈與遊玩節奏，定位改為整部遊戲的教學案件。

教學內容：

- 觀察場景與圖片
- 詢問人物
- 蒐集證物
- 解鎖新地點
- 使用身分／專業情報
- 提出證據
- 排除過度推論
- 完成多階段推理

案件本身仍以人為事件為主，不強迫加入真正靈異原因。

結案後可增加一個低強度伏筆：找回的筆記中存在一句與夜班返家、某條巷道及「不要回頭」有關的旁記。此伏筆不改變《失落的三頁》的真相，也不在當下解釋。

## 正式案件一（原案件二位置）：《雨夜敲門》

### 基本鉤子

1958 年秋，臺北。一名婦人委託主角調查家門在雨夜反覆傳出三次敲門聲的怪事。鄰里流傳「第三次不要開門」。幾日前，她的兒子開了門；此後家中開始出現新的異常。

### 第一章目標

第一章只建立謎團，不揭露案件最終屬於人為或靈異。

初始調查場景以委託人住宅及附近巷道為核心。可調查項目預定包括：

- 門板與門框的低位新刮痕
- 屋簷與雨水流向
- 巷道泥痕／鞋印
- 香爐與近期祭祀痕跡
- 曾被撕動的鎮宅符
- 兒子的房間
- 鄰居對「三次敲門」傳聞的不同版本

一般觀察與家學觀察應提供不同但相容的資訊。例如：一般觀察確認門框痕跡的位置與新舊；家學觀察判斷符紙的貼法、破損方向與民俗用途。兩者都不能單獨證明有鬼。

### 第一章結尾要求

玩家至少建立兩種仍可成立的解釋：

1. 有人利用地方怪談製造敲門事件。
2. 人為痕跡確實存在，但仍有一項事件無法由目前的人為行動時間線解釋。

第一章結束時開放下一個調查地點，而不是直接進入案件結論。

## 長篇案件規格

從《雨夜敲門》開始，每一案由多章節構成。每章至少應有一個新場景、一組人物／證詞、一項關鍵證物或異常、一個可被修正的假設，以及通往下一章的明確調查成果。

案件可以彼此完全無關，也可以共享人物、物件、地方傳說、符式或歷史紀錄。長期主線採「可回收伏筆」方式設計：早期線索即使後來沒有納入大主線，也必須能在原案件中獨立成立。

## 時代背景規則

歷史背景以 1958 年臺灣戒嚴社會為基準。政治、警政、戶籍、交通、勞動、媒體與地方生活只在與案件相關時進入敘事，不把所有恐懼都自動解釋成政治迫害。

民俗內容要區分：歷史可考的習俗、地方傳說、角色主觀信念，以及本作虛構的超自然設定。不可把遊戲虛構內容寫成真實歷史事實。

## 暫不鎖死的項目

- 超自然現象的最終宇宙規則
- 主角家族完整系譜
- 最終大型事件的幕後者／本質
- 全季案件數量
- 每個伏筆是否一定回收到主線

這些項目在實際完成《雨夜敲門》前幾章並取得遊玩回饋後再定稿。
